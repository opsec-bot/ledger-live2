Add an opt-in "Flex Mode" display setting (Settings > Accounts) that shows made-up portfolio and BTC/ETH/SOL/LTC balances for fun screenshots, instead of real balances. Each asset's quantity and fiat value are editable on a dedicated Flex Mode settings page — the two stay in sync through the current market price, and the portfolio total is always the sum of the per-asset values. It only affects display formatting on the Portfolio dashboard, assets list, analytics allocation and asset overview screens, never Send/Receive/Swap or transaction data, and always shows a persistent "Flex Mode" banner while active so it's never mistaken for real holdings.
